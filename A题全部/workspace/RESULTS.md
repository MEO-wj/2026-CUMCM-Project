# 药材烘干问题 计算结果报告

本报告汇总四个子问题的数值方法与结果。全部结果由 `code/` 下脚本真实运行产出，
非人工填写；权威标量存于 `figures/all_results.json`，各问明细存于
`figures/problem_N_results.json`，竞赛交付表存于工作区根目录 `result1.xlsx`–`result4.xlsx`。

## 数据使用声明（抽样透明）

本题为确定性偏微分方程数值求解，**全量计算、无抽样、无截断**：时间轴按题设步长
逐步推进（问题1：1800 s @1 s；问题2：3 h @1 s；问题3/4：至烘干终点 @60 s），
空间按 M=20 节点全场求解并映射到 21 个固定径向输出列。附件1（环境）与附件2（半径）
数据整表读入（`read_excel` 显式 `sheet_name`），未做任何行采样。故不存在
「以部分数据冒充全量」的降级。

## 统一数值内核（code/utils.py）

- **控制方程**：一维轴对称柱坐标耦合热-质传递
  ρc_p∂_tT=(1/r)∂_r(r k ∂_rT)、∂_tC=(1/r)∂_r(r D ∂_rC)。
- **离散**：节点中心守恒型有限体积法（FVM），柱测度权重
  w_j=ξ_{j+1/2}²−ξ_{j−1/2}²（离散测度和=1，误差 0）；中心奇点由最内侧内面面积
  恒为 0 结构性消去（非近似）。
- **界面扩散系数**：Kirchhoff 积分平均 Φ(C)=C e^{−a/C}−a E₁(a/C)（`scipy.special.exp1`），
  避免调和平均在 D 跨量级时被最小值锁死（对照见问题3）。
- **时间推进**：θ=1 向后欧拉 + Picard 内迭代（T、C 同一迭代回路，tol=1e-11，max=40）。
- **表面 Robin 边界**：−D∂_rC=h_m(C_s−C_air)、−k∂_rT=h(T_s−T_air)，带 r 权装配。
- **交叉复核**：解析 Bessel 级数（常物性退化）、`scipy.integrate.solve_ivp` BDF 独立复算、
  Richardson 空间收敛阶（M=20/40/80）。

## 问题1 预热平衡阶段（附录2 常物性，D 无温度项）

- **方法**：附录2 常物性 ρ=820、c_p=2600、k=0.36、h=25、h_m=8e-7；
  D=7e-9·exp(−0.89/C) 不含温度项。时程 1800 s、步长 1 s。
- **结果（t=1800 s 五点场，r=0/0.5/1.0/1.5/2.0 cm）**：
  - 温度 T：33.5764 / 33.7730 / 34.3651 / 35.3629 / 36.7860 ℃
  - 水分 C：2.5500 / 2.5496 / 2.5376 / 2.3763 / 1.5125 kg/kg
- **验证**：守恒残差 5.6e-16；Picard 残差 9.94e-12；表面控制体离散平衡残差 4.1e-14；
  D 对 T±10 K 扰动相对变化 0.0（确认无温度项）；D(C₀=2.55)=4.9377e-9；
  解析 Bessel 相对 L2 误差 2.8e-4；BDF 独立复算最大绝对差 5.77e-4（<1e-3）。
- **交付**：`result1.xlsx`（温度/水分浓度两表，1801×21）。

## 问题2 全过程（预热+恒温，附录3 变物性 + Arrhenius，开尔文）

- **方法**：附录3 变物性（ρ、c_p、k 随 C 逐点更新），D 随 C 与 T 按
  Arrhenius e^{−3850/T_K} 更新（T 取开尔文）；每步 Picard 内迭代。时程 3 h、步长 1 s。
- **结果（t=3 h 五点场）**：
  - 温度 T：49.8495 / 49.8554 / 49.8746 / 49.9101 / 49.9664 ℃
  - 水分 C：1.7662 / 1.7165 / 1.5701 / 1.3331 / 1.0078 kg/kg
- **验证**：守恒残差 4.8e-16；Picard 残差 9.997e-12 且单调下降（迭代 4 步）；
  k 径向离散度 0.1188（>1e-6，排除冻结常数）；开尔文入口断言 200<T_K<500 生效。
- **交付**：`result2.xlsx`（温度/水分浓度两表，10801×21）。

## 问题3 恒温烘干至中心达标（附录3 变物性，固定域）

- **方法**：终点判据取空间最大含水率 C_max(t)=max_r C(r,t) 首次 <0.15 kg/kg（首次穿越，
  未取整原始解上线性定位），步长 60 s。
- **结果**：烘干时长 **t\*=57.2621 h**；穿越值 C_max(t\*)=0.149995（前一步 0.150013）；
  终点 argmax_r=0（最湿在中心）；表面含水率 0.052497 ≥ 环境等效 0.049860。
- **验证**：守恒残差 4.4e-16；Picard 残差 9.986e-12；C_max 邻域单调下降；
  空间收敛阶 p=1.925（Richardson，M=20/40/80，≥1.7）；
  界面平均对照 CK7：Kirchhoff 57.26 h / 算术 56.23 h / 调和 557.76 h（调和被最小值锁死，佐证禁用）。
- **交付**：`result3.xlsx`（水分浓度单表，末行时间=t\*）。

## 问题4 收缩域烘干至中心达标（附录4 变物性，动边界 Landau 定域）

- **方法**：半径 R(t) 由附件2 PCHIP 单调保形插值（2.0→1.198 cm）给定；ξ=r/R(t) 定域，
  不变量 ρ_s R²=σ，收缩漂移相消后余 1/R(t)² 因子；物性换附录4（D 前因子 4.2e-4、指数 0.30）。
- **结果**：烘干时长 **t\*=50.8975 h**；R(t\*)=1.2 cm；终点 argmax_r=0。
- **验证**：守恒残差 3.3e-16（ρ_s R² 不变量成立，映射项无遗漏）；Picard 残差 9.998e-12；
  R(t) 复现附件2 相对误差 0.0（<1e-8）且单调非增；
  加密输出步长 t\*=50.8778 h 与主算相对差 0.04%（<0.2%，收敛性佐证）。
- **交付**：`result4.xlsx`（水分浓度单表，末列语义「药材表面」，超出 R(t) 的径向位置留空）。

## 灵敏度分析（figures/sensitivity_results.json）

- **环境外推方式**（末小时窗口 hold/mean/linear）：问题3 mean +0.53%（57.567 h）、
  linear −0.26%（57.115 h）；问题4 mean +0.53%（51.166 h）、linear −0.23%（50.782 h）。
- **表面蒸发潜热汇**（龙卷风）：问题3 计入潜热 e^{−3850/T_K}·D 反馈后 t\*=62.646 h，
  相对无潜热基准 +9.40%——故无潜热解为真实情形的下界。

## 方向/界一致性（logic_probes，均由扰动重算真实产出）

- **界探针**：固定域 t\*（129.25 h）为收缩真实情形（50.90 h）的上界，放开收缩→减小（sign=−1，与 upper 一致）；
  无潜热 t\*（57.26 h）为含潜热（62.65 h）的下界，计入→增大（sign=+1，与 lower 一致）。
- **单调探针**：T_air↑→t\*↓、h_m↑→t\*↓、R₀↑→t\*↑、C₀↑→t\*↑，四项实测符号与合同 expect_sign 全一致。
