# 药材烘干学术图像：前端渲染与使用说明

本目录直接保留 `00.svg`、`01.svg`–`16.svg`，以及对应的 PNG 预览和本说明，不创建图像子目录，不生成 PDF。`00.svg` 与确认版总体流程图保持一致；`01.svg`–`16.svg` 为前端渲染的 SVG 图，PNG仅作为预览和兼容格式。

`01.png`–`16.png` 不包含图号、标题、G 编号、制作标识或解释段落，只保留图形、坐标、单位、图例和必要的公式/数据标注。`00.png`为确认版总体流程图，保留输入、四问、模型结果和分析输出等原有信息。网页中的图名、目录编号和解释位于导出画布之外。

## 打开前端工作台

在仓库根目录执行：

```powershell
cd "学术图像"
npm ci
npm run build
npm start
```

打开 <http://127.0.0.1:5183/>。依赖已安装、页面已构建时只需 `npm start`。

开发时使用 `npm run dev`，地址为 <http://127.0.0.1:5182/>。代码更新后重新 `npm run build`，即可更新预览版。

页面支持切换全部16张图、标注字号、白色/透明背景、单图 PNG/SVG 下载和整套 ZIP 下载。PNG 可选1600×1000、3200×2000、4800×3000；SVG保留矢量曲线、坐标和文字，三维药材与热图色场以图像嵌入，不依赖外部贴图。PNG的中文/数学标注在当前浏览器中栅格化；SVG跨设备编辑需要相应字体。中文使用宋体，数字和英文优先使用 Times New Roman。

## 从当前结果复现全部16张图

需要 Node.js，以及安装了 NumPy 2.x、SciPy、openpyxl 的 Python；本机浏览器优先使用 Edge/Chrome。未安装系统 Chromium 浏览器的环境可运行 `npx playwright install chromium`。

```powershell
cd "学术图像"
npm run data
npm run build
npm run export
```

`data` 从原有 NPZ/XLSX 提取数据，不重新求解方程；`build` 构建前端；`export` 启动本地无界面浏览器，使用网页相同的渲染器与 PNG 编码器，覆盖本目录的16张 PNG。旧命令 `python scripts/build_core_figures_v2.py` 已转为此流程的兼容入口。

导出过程核对共同输出的一致性、画布标注边界和禁止出现的制作文字；检查记录及页面截图写在已忽略的 `学术图像/output/playwright/`，不混入本目录。导出不会自动提交 Git。

## 每张图的用途

| 文件 | 图形形式与展示内容 | 建议插入位置 | 主要作用及使用边界 |
|---|---|---|---|
| 00.svg | 总体研究流程图：观测输入、统一热质传递模型、问题一至问题四、数值核验与论文输出 | 第2节问题分析末尾，模型假设之前 | 与已确认的原版流程图保持一致，图内“数学模型”“模型验证与分析”“分析输出”是功能区标识，不是图号或外部标题。 |
| 01.svg | 三维药材、径向双量示意剖面、热流与水分通量 | 物理过程与模型假设 | 说明外部加热和内部向表面迁移。复用原理图的网格、材质与连续示意色场；上半温度、下半水分表示同一截面的不同物理量，不表示上下两种材料。不能从色场读取实际温度或含水率。 |
| 02.svg | 带图形模块的计算流程与反馈环 | 技术路线、数值求解流程 | 连接观测输入、物性、守恒通量、动边界映射和终点检验。图标为模块示意，不是实验拟合曲线。U表示单位体积存储量，V为控制体体积。 |
| 03.svg | 径向剖面与表面气膜局部展开 | 初边值条件 | 区分中心零梯度与表面Robin换热/传质；q按净输入热流定义，J按净输出水分通量定义。C∞是空气等效含水率。 |
| 04.svg | 环形控制体与相邻控制体局部展开 | 守恒型有限体积离散 | 展示环形体积测度、中心零通量和共享界面的通量配对。环数作示意性简化，不能当作实际计算网格；公式对应固定域控制体的存储量平衡。 |
| 05.svg | 物理域收缩、径向材料网格和固定区间映射 | 第四问动边界建模 | 展示ξ=r/R(t)、uᵣ=ξṘ(t)以及固定材料坐标范围。圆的大小为示意，不对应特定观测时刻。 |
| 06.svg | 观测/插值双面板，附平台估计窗口 | 数据预处理、环境边界输入 | 全部241个环境观测点均保留；灰区3–4 h包含61个样本。4 h后的虚线采用该窗口均值。上下分别是T∞与C∞，不是内部/表面响应，也不是相对湿度。 |
| 07.svg | 按半径比例绘制的阶段圆、半径观测曲线和导数面积图 | 第四问半径输入及插值 | 保留145个半径观测点；PCHIP与解析导数来自附件2。速率不是另一次实验测量；结束时刻虚线只标出第四问结果。 |
| 08.svg | 热/水分局部特征时间的对数图及比值图 | 热质扩散机制讨论 | 用第三问中心和表面状态计算τT、τC、α/D。使用第三问物性与R₀=0.02 m；局部尺度不是实测或求解的全程干燥时长。 |
| 09.svg | 第一问双场时空等值图与三时刻径向色盘 | 第一问结果 | 展示0–0.5 h温度、含水率及径向差异；色盘取0、0.3、0.5 h。温度与水分分别使用独立色标。 |
| 10.svg | 第二问双场时空图与径向剖面族 | 第二问结果、预热过程 | 展示0–3 h双场，以及0、1、2、3 h剖面。C保持干基含水率的原单位，不改写成C/C₀。 |
| 11.svg | 两张中性零差值矩阵及最大差值 | 一致性核验附录（备选） | 对3450个共同时间、21个物理半径全部核对；最大绝对差值均为0。色标±10⁻¹²仅为展示范围，不能解释为误差上限、误差估计或独立物理验证。 |
| 12.svg | 固定域全程响应、最大值包络与后期放大框 | 第三问终点与拖尾分析 | 展示中心/最大值、21点柱测度近似平均和表面值。终点57.4741 h按全域最大C≤0.15判定，不可用平均值提前结束。 |
| 13.svg | 终态径向色盘与5121节点剖面 | 第三、四问终态比较 | 固定域57.4741 h、收缩域51.0886 h分别达标；不是同一时刻。色盘按实际半径2.0/1.2 cm等比例绘制，剖面横坐标统一为ξ。 |
| 14.svg | 带R(t)边界和域外遮罩的含水率时空图、物理剖面族 | 第四问动边界结果 | 正确处理第四问最后一列actual_surface；每条剖面在实际表面终止，灰区为域外而非零含水率。终态R=1.2 cm。 |

正文不需要使用全部16张图。01/03可以择一概述机制；07与15按论证重点取舍；11通常更适合附录；12、13、14、16分别回答全程终点、终态分布、移动边界、情景差别，避免用它们重复说明同一个结论。

## 数据来源与显示规则

- 环境与半径观测：`代码/附件/附件1.xlsx`、`附件2.xlsx`。
- 定量结果：`题目要求结果数据/复算依据/result1_未舍入.npz`至`result4_未舍入.npz`。原求解器及NPZ均未改动。
- 前端数据：`学术图像/src/data.json`，由`学术图像/scripts/prepare_data.py`提取，包含每份源文件的SHA-256。
- 时间曲线使用原始时间样本抽取，预热阶段额外保留每分钟的输出；所有曲线保留首末点。不是在浏览器里重新拟合实验结论。
- 时空图在输出点间作可视化插值；第四问逐行使用真实物理半径和表面值，仅域内着色。热图和等值线表达的是显示重构，不能宣称增加了原求解精度。
- 13图终态剖面保留全部5121个节点。09图与13图色盘由相应径向剖面旋转显示，代表轴对称截面，不是二维独立测量。
- 12图平均含水率为21个输出半径上的`2∫C(ξ)ξdξ`梯形近似。达标采用生成记录的全域最大值判据。
- 图内`t*`对应现有生成记录的输出结束时刻，遵循原程序的四位小数处理规则，并非重新定位的未经舍入临界根。
- 01/03使用已有原理图的Three.js材质资源；纹理属于外观示意，不是实测组织或物种认定。参考实现与资源说明见`原理图/README.md`及`THIRD_PARTY_NOTICES.md`。
