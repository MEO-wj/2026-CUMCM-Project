# 2026 全国大学生数学建模竞赛 A 题

本仓库用于 **2026 年高教社杯全国大学生数学建模竞赛 A 题《药材的烘干问题》** 的资料整理、数学建模、数值计算、结果复核和论文协作。

## 题目概述

热风烘干包括预热平衡和恒温干燥两个阶段。药材近似为轴向足够长、径向对称的圆柱体，烘干过程中需要同时研究：

- 药材内部温度随时间和径向位置的变化；
- 药材内部水分浓度随时间和径向位置的变化；
- 满足含水率要求所需的最短烘干时间；
- 药材因失水收缩后，变半径条件下的烘干过程。

题目给定药材初始长度为 `25 cm`、初始半径为 `2 cm`、初始温度为 `28 °C`、初始水分浓度为 `2.55 kg/kg`。除题目特别说明外，所有计算结果保留四位小数。

## 目录职责

### `docs/`：原始资料

保存题目 PDF、官方附件、结果模板和论文格式规范。该目录中的文件不应被代码覆盖，也不应直接保存计算结果。

### `data/`：数据流水线

数据按处理阶段分层：

| 目录 | 用途 | 是否可手工修改 |
| --- | --- | --- |
| `data/raw/` | 外部原始数据、固定版本的数据副本 | 否 |
| `data/interim/` | 插值、清洗、单位转换、网格重采样结果 | 仅通过脚本生成 |
| `data/processed/` | 模型最终输入，例如统一为 SI 单位后的数据 | 仅通过脚本生成 |

当前 A 题官方原始数据仍直接位于 `docs/CUMCM2026赛题原题/A题/附件/`。如果后续为了复现实验需要复制到 `data/raw/`，必须在文件名或说明中记录来源和版本，避免出现两份不一致的附件。

### `code/a_drying/`：可复用代码

模型、求解器和分析逻辑都放在包内，便于被脚本、Notebook 和测试共同调用。不要把最终算法长期留在 Notebook 单元格中。

### `scripts/`：运行入口

脚本只负责组织任务和传递参数，例如：

```text
scripts/
├─ prepare_data.py       # 清洗附件并生成 data/processed/
├─ solve_problem1.py     # 求解问题 1
├─ solve_problem2.py     # 求解问题 2

```

脚本应从仓库根目录运行，并使用相对路径或项目根路径解析输入输出，不能依赖个人电脑的绝对路径。

### `results/`：计算产物

- `results/tables/`：提交用的 `result1.xlsx`、`result2.xlsx`、`result3.xlsx`、`result4.xlsx` 及论文表格；
- `results/figures/`：论文使用的最终图；
- `results/checkpoints/`：长时间计算的中间状态，只有确实需要复现或断点续算时才提交。

结果文件应由代码生成。修改模型后要重新生成受影响的结果，不要手工编辑旧结果冒充新结果。

### `paper/`：论文协作

- `paper/draft/`：论文正文、摘要、参考文献和版本草稿；
- `paper/figures/`：论文插图源文件或高分辨率导出文件；
- `paper/tables/`：论文表格源文件。

论文中出现的数字、表格和图应能追溯到 `results/` 中的具体结果文件或生成脚本。

## 四个问题

### 问题 1：预热平衡阶段

药材尺寸和初始状态：

- 长度：`25 cm`
- 半径：`2 cm`
- 初始温度：`28 °C`
- 初始水分浓度：`2.55 kg/kg`

需要建立预热平衡阶段的温度场和水分浓度场模型，并完成：

1. 在论文中填写指定时刻 `100、300、600、900、1200、1500、1800 s`；
2. 给出到药材中心距离 `0、0.5、1、1.5、2 cm` 处的温度和水分浓度；
3. 将 `0–1800 s` 内每隔 `1 s`、径向每隔 `0.1 cm` 的完整结果保存至 `result1.xlsx`；
4. `result1.xlsx` 中分别使用“温度”和“水分浓度”工作表。

问题 1 的参数：

| 参数 | 数值 | 单位 |
| --- | ---: | --- |
| 密度 `ρ` | `820` | `kg/m³` |
| 比热容 `c_p` | `2600` | `J/(kg·K)` |
| 热传导系数 `k` | `0.36` | `W/(m·K)` |
| 对流换热系数 | `25` | `W/(m²·K)` |
| 对流传质系数 | `8 × 10⁻⁷` | `m/s` |

水分浓度扩散系数：

```text
D(C) = 7 × 10⁻⁹ exp(-0.89 / C)  m²/s
```

### 问题 2：整个烘干过程

需要同时考虑预热平衡阶段和恒温干燥阶段，建立整个烘干过程的温度场和水分浓度场模型。题目要求：

1. 在论文中给出 `0.5、1.0、1.5、2.0、2.5、3.0 h` 的结果；
2. 给出到药材中心距离 `0、0.5、1、1.5、2 cm` 处的温度和水分浓度；
3. 将 `0–3 h` 内每隔 `1 s`、径向每隔 `0.1 cm` 的完整结果保存至 `result2.xlsx`；
4. `result2.xlsx` 中分别使用“温度”和“水分浓度”工作表。

问题 2 使用附录 3 的经验公式：

```text
ρ(C)   = 650 + 128C
c_p(C) = 1450 + 2736 × C/(C + 1)
k(C)   = 0.21 + 0.38 × C/(C + 1)
D(C,T) = 2.4 × 10⁻³ exp(-0.45 / C) exp(-3850 / T)
```

其中 `T` 必须使用绝对温度 `K`，`C` 的单位为 `kg/kg`。

### 问题 3：达到含水率要求的时间

按照题目要求，药材各处的水分浓度均应低于 `0.15 kg/kg`。需要确定达到该要求的烘干时间，单位为小时。

输出要求：

1. 在论文中按每隔 `6 h` 的时间间隔给出结果；
2. 径向位置为到药材中心距离 `0、0.5、1、1.5、2 cm`；
3. 最后一行填写烘干结束时间；
4. 将药材内部水分浓度按每隔 `60 s`、径向每隔 `0.1 cm` 的完整结果保存至 `result3.xlsx`。

建议将烘干结束时间定义为：

```text
t* = min { t : max_r C(r,t) < 0.15 }
```

实际计算时应明确是否采用严格小于号、数值时间步长和插值方式，并在论文中保持定义一致。

### 问题 4：考虑收缩的烘干过程

实际烘干中药材会因水分流失而发生尺寸变化。需要结合附件 2 的半径数据，并使用附录 4 的经验公式，重新确定烘干时长。

输出要求：

1. 在论文中按每隔 `6 h` 给出水分浓度；
2. 位置从药材中心到药材表面按每隔 `0.5 cm` 给出；
3. 表格最后一列表示“药材表面”；
4. 将内部水分浓度按每隔 `60 s`、空间每隔 `0.1 cm` 的完整结果保存至 `result4.xlsx`；
5. 说明收缩边界的处理方式，以及时刻与半径数据之间的插值或分段处理。

问题 4 使用附录 4 的经验公式：

```text
ρ(C)   = 760 + 90C
c_p(C) = 1850 + 2150 × C/(C + 1)
k(C)   = 0.12 + 0.20 × C/(C + 1)
D(C,T) = 4.2 × 10⁻⁴ exp(-0.30 / C) exp(-3850 / T)
```

附件 2 的数据范围为 `0–259200 s`，采样间隔为 `1800 s`，半径从 `2 cm` 变化至 `1.198 cm`。计算中需统一长度单位；若公式采用国际单位制，应将厘米转换为米。

## 统一建模约定

### 空间变量

采用圆柱径向一维模型：

- `r`：到药材中心的径向距离；
- `R(t)`：时刻 `t` 的药材半径；
- 问题 1–3 中 `R(t)=2 cm`；
- 问题 4 中 `R(t)` 由附件 2 给定。

忽略轴向和周向变化，中心位置采用轴对称边界条件。典型控制方程可写成：

```text
ρ c_p ∂T/∂t = (1/r) ∂/∂r (r k ∂T/∂r)
∂C/∂t     = (1/r) ∂/∂r (r D ∂C/∂r)
```

具体边界条件、初始条件和热质传递耦合方式以题目公式、参数和最终建模假设为准。建议在代码和论文中明确区分：

- 中心对称边界：`∂T/∂r = 0`、`∂C/∂r = 0`；
- 药材表面：对流换热和对流传质边界；
- 烘房环境：由附件 1 或题目给定的恒温干燥条件提供；
- 收缩问题：在 `r=R(t)` 处施加移动边界，并同步更新空间网格。

### 单位约定

代码内部建议统一采用 SI 单位：

- 长度：`m`
- 时间：`s`
- 温度：`K`
- 水分浓度：`kg/kg`
- 密度：`kg/m³`
- 热传导系数：`W/(m·K)`
- 扩散系数：`m²/s`

展示给论文和 Excel 的距离按题目要求使用 `cm`，温度按题目要求使用 `°C`，水分浓度保留四位小数。

## 建议的实现流程

1. **数据预处理**：读取附件 1 和附件 2，统一单位，检查缺失值、重复值和采样间隔。
2. **模型离散化**：优先采用径向有限差分或有限体积方法，处理 `r=0` 的轴对称离散格式。
3. **问题 1 求解**：使用常参数和附件 1 的边界数据，验证温度和水分浓度场的基本趋势。
4. **问题 2 求解**：将 `ρ、c_p、k、D` 更新为 `C` 或 `T` 的函数，处理预热与恒温阶段的分段边界。
5. **问题 3 判定**：在每个时间步计算全域最大水分浓度，定位首次满足阈值的时间。
6. **问题 4 求解**：根据 `R(t)` 更新移动边界和空间网格，输出相对于当前半径的内部剖面。
7. **结果验证**：检查中心与表面温度差异、含水率单调性、边界通量、网格收敛性和时间步长敏感性。
8. **结果导出**：生成 `result1.xlsx–result4.xlsx`，统一格式、精度和单位。
9. **论文整理**：将模型假设、方程、离散格式、算法流程、参数来源、误差分析和敏感性分析写入论文。
