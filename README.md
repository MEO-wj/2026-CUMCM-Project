## 题目概述

热风烘干包括预热平衡和恒温干燥两个阶段。药材近似为轴向足够长、径向对称的圆柱体，烘干过程中需要同时研究：

- 药材内部温度随时间和径向位置的变化；
- 药材内部水分浓度随时间和径向位置的变化；
- 满足含水率要求所需的最短烘干时间；
- 药材因失水收缩后，变半径条件下的烘干过程。

题目给定药材初始长度为 `25 cm`、初始半径为 `2 cm`、初始温度为 `28 °C`、初始水分浓度为 `2.55 kg/kg`。除题目特别说明外，所有计算结果保留四位小数。

### 问题 3：达到含水率要求的时间

## 统一建模约定

### 空间变量

采用圆柱径向一维模型：

- `r`：到药材中心的径向距离；
- `R(t)`：时刻 `t` 的药材半径；
- 问题 1–3 中 `R(t)=2 cm`；
- 问题 4 中 `R(t)` 由附件 2 给定。

忽略轴向和周向变化，中心位置采用轴对称边界条件。典型控制方程可写成：

```text
ρ c_p ∂T/∂t = (1/r) ∂/∂r (r k ∂T/∂r)
∂C/∂t     = (1/r) ∂/∂r (r D ∂C/∂r)
```

具体边界条件、初始条件和热质传递耦合方式以题目公式、参数和最终建模假设为准。建议在代码和论文中明确区分：

- 中心对称边界：`∂T/∂r = 0`、`∂C/∂r = 0`；
- 药材表面：对流换热和对流传质边界；
- 烘房环境：由附件 1 或题目给定的恒温干燥条件提供；
- 收缩问题：在 `r=R(t)` 处施加移动边界，并同步更新空间网格。

### 单位约定

代码内部建议统一采用 SI 单位：

- 长度：`m`
- 时间：`s`
- 温度：`K`
- 水分浓度：`kg/kg`
- 密度：`kg/m³`
- 热传导系数：`W/(m·K)`
- 扩散系数：`m²/s`

展示给论文和 Excel 的距离按题目要求使用 `cm`，温度按题目要求使用 `°C`，水分浓度保留四位小数。

## 建议的实现流程

1. **数据预处理**：读取附件 1 和附件 2，统一单位，检查缺失值、重复值和采样间隔。
2. **模型离散化**：优先采用径向有限差分或有限体积方法，处理 `r=0` 的轴对称离散格式。
3. **问题 1 求解**：使用常参数和附件 1 的边界数据，验证温度和水分浓度场的基本趋势。
4. **问题 2 求解**：将 `ρ、c_p、k、D` 更新为 `C` 或 `T` 的函数，处理预热与恒温阶段的分段边界。
5. **问题 3 判定**：在每个时间步计算全域最大水分浓度，定位首次满足阈值的时间。
6. **问题 4 求解**：根据 `R(t)` 更新移动边界和空间网格，输出相对于当前半径的内部剖面。
7. **结果验证**：检查中心与表面温度差异、含水率单调性、边界通量、网格收敛性和时间步长敏感性。
8. **结果导出**：生成 `result1.xlsx–result4.xlsx`，统一格式、精度和单位。
9. **论文整理**：将模型假设、方程、离散格式、算法流程、参数来源、误差分析和敏感性分析写入论文。

## 建议的代码组织

```text
code/a_drying/
├─ data/                  # Excel 读取、校验和插值
├─ models/                # 常数、经验公式、控制方程和边界条件
├─ solvers/               # 空间离散和时间推进
├─ analysis/              # 阈值判定、统计、误差和敏感性分析
└─ visualization/         # 诊断图和论文图
```

实现时应尽量把“模型参数”“求解器”“结果导出”分开，避免在 notebook 或单个脚本中重复复制四个问题的核心逻辑。

## 协作约定

### 分支与提交

建议使用以下分支命名：

```text
model/<topic>       # 建模和方程
solver/<topic>      # 数值求解
data/<topic>        # 数据处理
figure/<topic>      # 图表
paper/<topic>       # 论文
fix/<topic>         # 修复问题
```

提交信息建议包含明确动作，例如：

```text
feat: add fixed-radius radial solver
fix: correct center boundary discretization
docs: update problem 3 threshold definition
```

### 提交前检查

- 代码可重复运行，输入文件路径不依赖个人电脑绝对路径；
- 结果文件可由代码重新生成；
- 关键参数和单位有注释或文档说明；
- 论文中的表格、图和 Excel 输出来自同一版本结果；
- 不提交临时文件、缓存、个人环境配置和无关题目文件；
- 对算法改动至少进行一次数值 sanity check 或回归对比。
