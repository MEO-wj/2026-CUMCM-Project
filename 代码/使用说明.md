# 求解代码使用说明

每个问题目录内只有一个独立入口 main.py，不需要从其他问题导入代码，不包含绘图。

## 安装依赖

本次验证环境：Python 3.14.6、NumPy 2.5.1、SciPy 1.18.0、openpyxl 3.1.5。

    python -m pip install numpy==2.5.1 scipy==1.18.0 openpyxl==3.1.5

## 运行

在本“代码”目录打开终端，按需运行：

    python 问题1/main.py
    python 问题2/main.py
    python 问题3/main.py
    python 问题4/main.py

四份完整结果生成后，在同一目录运行：

    python 整理表1到表6.py

该命令直接从四份 result 文件摘取论文表1～表6，保存到“题目要求结果数据/表1到表6/表1到表6.xlsx”，包含六张工作表，不重新计算或手工改写结果。表1、2时间用秒，表3～6用小时；表5、6保留实际结束行。表6按每0.5cm取仍在药材内的固定位置，并单列当时实际表面。

表1、3的温度单位为℃；表2、4、5、6的水分浓度单位为kg水/kg干物质（干基含水率）。各表径向距离单位均为cm。

默认读取本目录“附件”中的两份原始数据，输出到本目录旁边的“题目要求结果数据”。
也可显式指定输入与输出目录：

    python 问题2/main.py --input-dir 附件 --output-dir ../题目要求结果数据

    python 整理表1到表6.py --result-dir ../题目要求结果数据

脚本会计算临界时间，然后根据已声明的规则求实际结束状态；没有把答案时长写死。
问题2与问题3采用相同全程计算规则，问题2逐秒导出两场，问题3从同一逐秒轨迹抽取每60秒水分。

## 数值与文件约定

- 观测区间用原附件线性插值；之后采用末一小时61个样本的算术平均平台。
- 不考虑蒸发潜热；问题4采用均匀材料共动收缩和原半径PCHIP。
- 全场统一采用 (4×5120网格结果−2560网格结果)/3，不按单个位置混选数值。
- Excel中的结果值、时间和数值半径表头均以数值存储并显示四位小数。
- “复算依据”目录保存未舍入统一场、两主网格直接场和生成记录。严格低于0.15的判定使用未舍入场；Excel末行显示0.1500不代表原始计算值等于0.15。
- 问题4超出当前半径的固定位置为空，最后一列始终是当时实际表面。
- 运行时自动固定数值库为单线程。默认网格用于本次正式结果；更改网格或依赖版本后，应重新核对数值，不直接覆盖论文结果。

这些代码对应审查报告选定的径向有效模型，不能把数值收敛解释成所有物理近似都没有误差。
