# 使用说明

先阅读 **实算结果报告.md**。第11节集中说明灵敏度分析可以支持哪些论文结论，第12节提供可改写进论文的正文表述。

## 文件安排

- 结果表：可直接用于查看和制表的CSV，包含时长灵敏度、场值响应、逐点响应、交互、输入情景与网格收敛。
- 计算结果/完整结果.json：115个唯一配置的最终未舍入观察量、网格与时间比较、工作误差预算、分析汇总及验证结果。它是整理后的最终数据，不是开发过程日志。
- 输入资料：原始附件1、2，各唯一工况定义、一份带执行补充的方案和网络试点配置。没有另存重复的数值输入缓存。
- 复算代码：普通电脑CPU可运行的中文入口；无需设备专用配置。

## 重算一个工况

在本目录运行：

```bash
python3 复算代码/运行分析.py --select Q1_baseline --cells 320 --precision production --jobs 1 --tag 新复算基准
```

输出写入新的“复算输出/新复算基准”。输入直接读取“输入资料/附件1.xlsx”和“附件2.xlsx”。--select选择全部工况.json中的ID；不指定则计算该文件中的全部配置。--cells指定较粗网格区间数，另一格为其两倍。--jobs只控制普通CPU工作进程数，可按本机能力选择。原报告和最终表不会被覆盖。

主程序依赖NumPy、SciPy、openpyxl。数值预算入口使用同一组通用科学计算库；网络试点另外需要PyTorch；制造解符号核对需要SymPy。实际软件版本记录在完整结果.json的“软件”条目。

## 三网格与时间误差复核

对同一--select分别生成320/640的production、640/1280的production、tight和tight_cap四组结果，再将四份对应JSON路径交给数值误差预算.py的--low、--middle、--tight、--cap。它会核对工况身份、参数、网格和时间设置。tight_cap15是已说明的追加时间控制，不能冒充普通默认精度。

独立空间复核.py提供已报告的等截面积单元与代数Robin方法，例如：

```bash
python3 复算代码/独立空间复核.py --select Q23_B_scale_plus1pct --cells 640,1280 --jobs 1 --tag 独立复算
```

它支持本次E0平台下的基准和参数代表工况，不能把入口存在说成所有情景都已作独立空间验证。

制造解可用运行分析.py的--cases 输入资料/模型核验工况.json重新积分；公式及解析参考由制造解参考.py提供。傅里叶网络核验.py提供已执行的限时试点方法；本次MMS试点没有通过预注册门，因此不提供未采用的权重文件，也未把真实窗口和额外种子写成已完成。

## 精度与复算范围

结果表的显示位数用于核对。工作区间是条件性数值估计，不是实验置信区间；Q23导热系数的5%内部目标略超等限制见报告。原生中间网格、调试输出、测试副本、旧版本和重复备份已从交付目录移出；需要重新检查原生网格时，由同一输入和代码重新生成。原题已有正式结果文件没有修改。
