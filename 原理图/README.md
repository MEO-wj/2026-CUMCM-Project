# 药材烘干原理图

本地运行的 Three.js 绘图页面，按提供的参考图组织完整药材、温度横截面和三个阶段的剖开视图。页面预览和导出使用同一套几何、材质、标注与色标。

## 打开

安装 Bun 后，在仓库根目录执行：

```sh
cd "原理图"
bun install
bun run build
bun start
```

浏览器打开 <http://127.0.0.1:5180/>。依赖已经安装、网页已经构建时，只需 `bun start`。`bun run build` 生成网页文件，不会生成原理图成品。开发检查使用 `bun run dev`，地址为 <http://127.0.0.1:5181/>，与用户预览分开；候选核对完成后重新构建即可更新预览。

## 画面与导出

- **细纵皱根段**：以黄芪／甘草式外观为参考，浅黄褐薄表皮、细纵皱和短纤维端面。
- **粉质切段**：以葛根／山药式外观为参考，较薄的灰褐表皮、浅色粉质端面。
- 中央截面可选“复合示意 · 原版”和“上下分区”：后者上半只按温度着色，下半只按含水率着色。两半展示同一径向截面的不同物理量，不表示药材上下实际存在两种材料或状态；每次打开页面默认使用原版复合示意。
- 截面内红色箭头向内、蓝色箭头向外，长度一致。复合模式各有 8 个，红蓝方向错开 22.5°；上下分区模式上红、下蓝各 4 个，直接显示，无需另行开启。
- 观察角度、表皮纹理强度和标注字号可以调整。
- 背景可选白色或透明。透明预览中的棋盘格只是页面背景，不写入导出文件；物体的半透明软阴影会保留。
- PNG 支持 1×、2×、3×。SVG 保留矢量文字、尺寸线和箭头，三维物体以图像嵌入，打开时不依赖外部贴图文件。
- 只有点击右上角的导出按钮才会生成下载；页面加载和切换设置不会自动下载。
- 中文使用宋体（macOS 为 `Songti SC`，Windows 回退 `SimSun`），英文与数字使用 `Times New Roman`。SVG 中保留字体名称；跨设备编辑 SVG 需要安装相应字体。PNG 在当前设备栅格化后不再依赖字体。

## 科学含义与外观范围

图中初始名义尺寸为长 25 cm、半径 2 cm，初温为 28 °C，初始干基含水率为 2.55 kg/kg。

题面没有指定药材品种，两种模式是外观示意，不作物种或组织学认定。材质贴图为生成的视觉资产；表面起伏与凹凸参数仅用于表现材质，不是实测形貌，也不改变求解模型参数。

复合模式下，中间横截面和右侧圆柱透视窗口同时显示暖色受热层和蓝色含水层，蓝色箭头表达净干燥时水分由内部向表面迁移。侧面保留部分自然表皮，端面显示完整复合剖面。初始温度和含水率均为常量；均匀初始材料仍可因透视路径和材质明暗呈现不同颜色。

上下分区模式仅改变中央截面及其温度色标，右侧阶段图仍采用复合示意。恒温干燥阶段使用由中心暖金橙色向外缘橙红色过渡的径向预设，表现预热后整体较暖、仍存在内外差异的状态；残余水分的视觉叠加减弱，避免把暖色中心冲淡为近白色。

颜色来自预设的连续径向示意函数及视觉叠加，未接入数值求解结果，不应从复合颜色中逐点读取具体温度、含水率或阶段时长。轴向视图作示意性压缩，透视效果不是光学测量结果。

## 实现位置

- `src/render.js`：药材网格、材质、相机、光照与透明渲染。
- `src/softShadow.js`：基于真实深度遮挡的 PCSS 软阴影；接触附近较清晰，离开接触处逐渐变软。
- `src/colorScale.js`：Oklab 三次样条色标；GPU 色场与 SVG 图例共享同一颜色函数。
- `src/figure.js`：整图排版、中文说明、尺寸线和箭头。
- `src/main.js`、`src/style.css`：预览设置及用户触发的 PNG／SVG 下载。
- `public/textures/`：三维模型使用的材质资产。

色彩插值参考 [D3 的 basis 插值](https://d3js.org/d3-interpolate/color#interpolateRgbBasis) 与 [Oklab 作者的转换公式](https://bottosson.github.io/posts/oklab/)。线性工作空间、输出转换和材质 API 对照 [Three.js r171](https://github.com/mrdoob/three.js/tree/r171) 核对。授权说明见 `THIRD_PARTY_NOTICES.md`。

软阴影参考 [Three.js 的 PCSS 示例](https://github.com/mrdoob/three.js/blob/r171/examples/webgl_shadowmap_pcss.html) 和 [Drei SoftShadows](https://github.com/pmndrs/drei/blob/master/src/core/softShadows.tsx)，按本项目的正交光源相机实现深度换算。渲染区域预留透明余量，避免半影被图像边缘截断；余量不改变药材和标注的位置、大小。
